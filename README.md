# Axonbyok

Installers for **Axonbyok**, the AI app for Windows that runs on your own API keys, by PAIXAI ONE.

**Download:** [Axonbyok-Setup.exe](https://github.com/HARDYxAI/axonbyok-releases/releases/latest/download/Axonbyok-Setup.exe) (latest version, Windows 10 and 11) · [axonbyok.space](https://axonbyok.space)

The installer isn't code-signed yet, so Windows may say it protected your PC: choose **More info**, then **Run anyway**. Each release lists the installer's SHA-256, which `Get-FileHash .\Axonbyok-Setup.exe` shows on your PC.

This repository holds only the installers; the app's code isn't published.
